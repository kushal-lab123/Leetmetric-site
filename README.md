# LeetMetric
A simple web app that shows your LeetCode problem-solving stats by username.

## Tech
- HTML, CSS, JavaScript (vanilla)
- Uses [leetcode-stats-api](https://github.com/tashifkhan/leetcode-stats-api) 
  by Tashif Ahmad Khan
